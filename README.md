# TM470-project-files
TM470 refers to the dissertation module of the BSc Computing and IT degree at the Open University.  

My choice of project involved building a React Native application featuring a 2-D game using the PixiJS framework and served via ExpressJS and MongoDB.  The purpose was to provide a promotional application for a local cafe.

This repo contains only the code files I contributed to the project and the final project report describing the purpose and outcome of the project.  Files beginning with a lower case letter relate to the application backend, while files relating to the game and React app begin with an uppercase letter.
